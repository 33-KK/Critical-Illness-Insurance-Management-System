## 一、建立一组容易复算的测试数据

使用 `reviewer` 登录。

1. 在「保险方案」新增方案：编码 `TEST70-1018-01`，名称「手工测试70%」，A/B/C 三类报销率均填写 **70**，状态启用。页面单位是百分比，应填写 70；API 的对应费率是 0.70。
2. 在「手术档案」新增项目：编码 `TEST-S300-1018-01`，名称「手工测试手术300元」，分类「测试科室」，单价 **300.00 元**，状态启用。
3. 在「参保档案」新增两位虚构参保人，均关联刚建立的方案并启用：

| 姓名 | 证件号码 | 医保卡号 | 初始余额 |
|---|---|---|---:|
| 手工测试通过 | TEST-ID-1018-A | TEST-CARD-1018-A | 0.00 |
| 手工测试拒赔 | TEST-ID-1018-B | TEST-CARD-1018-B | 0.00 |

联系电话可留空，其他必填项按页面填写。上述标识为测试字符串；不要录入真实个人资料。若提示编码或卡号已存在，换一组编号继续，不修改已有测试记录。

## 二、测试审核通过

1. 退出后用 `admin` 登录，在「参保档案」搜索「手工测试通过」，点击该行「充值」，充值 **1000.00 元**。
2. 换 `doctor` 登录，在「就诊登记」点击「新建就诊」，选择该参保人和 A 类门诊。
3. 独立诊断费用填 **100.00 元**，临床诊断填「手工测试审核通过」；添加刚建立的手术，数量 **2**。
4. 核对费用预览后点击「提交就诊登记」，记录生成的就诊单号。
5. 换 `reviewer` 登录，进入「报销审核」，找到刚才的单号，点击「去审核」，查看详情并点击「审核通过」。
6. 换 `admin` 查看该人的余额和「资金流水」，核对下表。

| 检查项 | 预期结果 |
|---|---:|
| 手术费用 | 300 × 2 = 600.00 元 |
| 总费用 | 100 + 600 = 700.00 元 |
| 拟报销 | 700 × 70% = 490.00 元 |
| 自付 | 700 − 490 = 210.00 元 |
| 提交就诊后的卡余额 | 1000 − 210 = 790.00 元 |
| 审核通过后的卡余额 | 仍为 790.00 元 |

审核状态应为「审核通过」，支付状态应为「已结算」。审核通过记录模拟医院结算，不再次扣患者余额。详情应显示登记时的手术价格、数量、费率和审核轨迹。

## 三、测试拒赔、部分补缴与结清

对第二位「手工测试拒赔」执行：

1. `admin` 充值 **300.00 元**。
2. `doctor` 按上一例登记：A 类、诊断费 100、测试手术单价 300、数量 2，临床诊断写「手工测试拒赔」。预期总额 700、自付 210、拟报销 490。
3. `reviewer` 在对应申请详情中点击「拒绝报销」，填写「手工测试材料不符」并确认。
4. `admin` 查看余额与待补缴：应为余额 0、待补缴 400。
5. `admin` 为该人充值 **200.00 元**，然后到「就诊登记」中找到该单，点击「补缴」并确认。
6. 再充值 **200.00 元**，再执行一次「补缴」，确认欠款结清。

| 完成动作 | 卡余额 / 元 | 待补缴 / 元 |
|---|---:|---:|
| 初始 | 0.00 | 0.00 |
| 充值 300 | 300.00 | 0.00 |
| 提交就诊，扣自付 210 | 90.00 | 0.00 |
| 拒赔，拟补扣 490，实际扣 90 | 0.00 | 400.00 |
| 充值 200，尚未点击补缴 | 200.00 | 400.00 |
| 第一次补缴 | 0.00 | 200.00 |
| 再充值 200 | 200.00 | 200.00 |
| 第二次补缴 | 0.00 | 0.00 |

充值不会自动抵扣欠款。欠款未结清时，医生不应能为该人提交新的就诊。最终审核状态仍为「审核拒绝」，支付状态应变为「已缴清」，并保留原拒绝原因。

## 四、进一步检查

| 测试 | 预期结果 |
|---|---|
| 医生登录后查看菜单 | 能新建就诊；没有审核、充值和账号管理操作 |
| 管理员查看菜单 | 有充值及系统管理；默认没有维护参保档案、保险和手术的新增权限 |
| 错误验证码、错误密码 | 给出错误提示，不能登录；重新获取验证码后再试 |
| 尝试充值 0、负数或超过 50000 | 前端或服务端拒绝，余额不变 |
| 新建零余额参保人后直接登记有自付费用的就诊 | 提示余额不足，不能扣成负数 |
| 对已经审核过的单据重新打开详情 | 没有再次审核的可用操作 |
| 修改专用测试方案的费率或手术价格 | 已提交单据保留旧快照；新试算使用新配置 |
| 刷新页面，再次查询刚才单据 | 数据仍在，金额和状态不变 |
| 工作台刷新、切换页面后回来、调整窗口宽度 | 图表无重叠、空白或重复叠加，能适应容器 |
| 文件上传后下载一个自己创建的测试文本文件 | 内容完整；不同普通用户不能下载不属于自己的文件 |

测试费率快照时只修改上面新增的测试方案和手术，后续若继续使用 700/490/210 的算例，请先恢复 70% 和 300 元。审核通过和拒赔使用不同单据，不对同一单切换审核决定。
