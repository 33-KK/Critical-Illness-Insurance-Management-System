## 改版前的问题（历史记录）

以下记录基于改版前的 `docs/screenshots/dashboard.png`、`login.png` 和旧样式代码，用于说明本次调整原因，不代表当前蓝白版界面。

- 表格正文多为 11px，表头 10px，部分说明文字仅 8~9px；浅灰绿辅助文字的对比度偏低。
- 较高表格行、大统计卡和图表占用首屏，最近业务与快捷办理排得较后，留白与内容密度不协调。
- 登录页与业务页的主色不统一，青绿、橄榄绿、暖灰底和深色侧栏叠加，视觉重点分散。
- 管理员菜单较长，业务与系统配置需要更清晰的分组。
- 登录页品牌展示面积大，较矮窗口中表单和演示角色入口不够集中。

## 已落地的设计

保留现有业务流程，以三个角色的任务为入口，统一蓝色主操作、冷灰背景和白色内容区。正文与表格主体采用 14px，状态仍通过文字与颜色共同区分。

| 页面     | 实际调整                                                                          |
| -------- | --------------------------------------------------------------------------------- |
| 全局     | 统一蓝白配色、边框、圆角、间距与状态色，提高文字对比；保留加载、错误和空状态      |
| 导航     | 白色侧栏按业务分组，“系统管理”可折叠，菜单继续按实际权限生成；手机端使用抽屉导航  |
| 工作台   | 按管理员、医生、审核员展示对应待办和快捷办理；近期业务优先，趋势图作为辅助信息    |
| 参保档案 | 姓名、卡号、方案与资金状态形成清晰层级；搜索、筛选、主要操作集中在表格上方        |
| 就诊登记 | 患者信息、诊断与手术分区；费用卡明确展示总费用、自付、拟报销与扣款后余额          |
| 报销审核 | 抽屉中分层展示单据概要、费用拆分、价格费率快照与审核记录；审核动作固定在底部      |
| 登录     | 白色品牌栏与独立登录卡片，保留验证码和三个演示角色；手机端优先展示表单与账号入口  |
| 移动端   | 适配 390px 宽度：收起侧栏、表单单列、费用信息纵向排列，审核详情和操作区随屏幕调整 |

三角色权限、医生数据范围、费用试算失效处理、余额和欠款限制、最终拒赔提示、充值与补缴确认、防重复提交等业务规则继续保留。真实医保、支付和短信接入已取消，系统仍使用模拟账务。
